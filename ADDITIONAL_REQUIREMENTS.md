# Проверка дополнительных требований

Дата: 05.11.2026. Проект: `C:\Users\M0zik\source\repos\CurrencyConverter2`.

## 1. Свой сервер и кеш — подтверждено

MAUI использует `HttpRatesService`, который обращается к настроенному серверу по `/api/rates?date=yyyy-MM-dd`. Адрес источника cbr-xml-daily.ru используется сервером, прямых запросов к нему в приложении нет. На Android-эмуляторе адрес компьютера — `http://10.0.2.2:5080/`.

`CbrRatesProvider` зарегистрирован как Singleton. Кеш хранится в памяти и в `src/CurrencyConverter.Server/App_Data/rates-cache`. Успешные исторические ответы хранятся 365 дней; недавние ответы и отсутствие данных (404) — 30 минут. Параллельные запросы объединяются семафором. После перезапуска данные читаются с диска.

Проверка настоящими HTTP-запросами: выбранная дата 03.02.2025, фактическая дата 01.02.2025, 44 валюты. После первого запроса в журнале 3 обращения к источнику (поиск предыдущих дней); после повторного их осталось 3. Ответы совпадают. Отдельный unit-тест подтверждает чтение дискового кеша новым экземпляром provider при недоступном источнике.

Сервер запущен локально. Интернет-хостинг не развёрнут: для работы на другом компьютере или телефоне требуется доступный адрес своего сервера.

```powershell

```

Результат: 30 пройдено, 0 ошибок, 0 пропусков. Из них 23 тестовых случая ViewModel, 5 серверного кеша, 2 HTTP/сериализации.

Проверяется ввод с обеих сторон, смена валют, номинал 100, запятая/точка, ошибочный и пустой ввод, сохранение/восстановление, работа с сохранёнными курсами без сети, фактическая дата курса, устаревшие асинхронные ответы, CanExecute и обмен валют без накопления округления.

Первый повторный запуск сборки встретил блокировку DLL работающим локальным сервером. Сервер временно остановлен; повторная сборка и все тесты прошли, затем сервер запущен снова.

## 3. GitHub Actions — подготовлено, выполнение ещё не подтверждено

Файл `.github/workflows/build.yml` запускается на push, pull_request и вручную. Сначала на Ubuntu выполняются тесты и публикуется сервер. Сборки Android/Windows и iOS Simulator/Mac Catalyst имеют `needs: tests-and-server`: при ошибке тестов они не начнутся. Результаты тестов TRX и сборки сохраняются как artifacts.

Проверены пути нового проекта, закрепление SDK 9.0.318, состав официального workload-набора 9.0.314.3 (NuGet-пакет Microsoft.NET.Workloads.9.0.300 версии 9.314.3): MAUI 9.0.120 и Apple SDK 26.5.9002. В workflow выбран Xcode 26.5; он указан в официальном списке ПО runner macos-26.

Источники проверки конфигурации:

- https://api.nuget.org/v3-flatcontainer/microsoft.net.workloads.9.0.300/9.314.3/microsoft.net.workloads.9.0.300.9.314.3.nupkg
- https://github.com/actions/runner-images/blob/main/images/macos/macos-26-Readme.md

Важно: эти проверки подтверждают согласованность конфигурации, но не заменяют реальный запуск на GitHub. Изменения ещё локальные, а сохранённая origin/main содержит исходный пустой шаблон без `.github/workflows/build.yml`. Фактическое выполнение Actions этой версии не проверено.
